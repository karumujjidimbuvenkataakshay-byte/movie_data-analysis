# 🎬 Movie Rating Analysis Using Python

Movie Rating Analysis is a data science project built using Python and Streamlit to analyze and visualize movie ratings across different genres. The project helps in understanding audience preferences and rating trends through interactive dashboards.

---

## 📌 Project Overview

This dashboard allows users to:
- Explore movie ratings interactively
- Filter movies by genre
- View average ratings for each genre
- Inspect individual movie details
- Understand rating patterns using visualizations

---

## 🛠️ Technologies Used

- Python  
- Streamlit  
- Pandas  
- Matplotlib
